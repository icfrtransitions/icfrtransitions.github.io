# Query set Q2: frozen record

ICFR Transitions Study. Registered protocol v1.4: https://osf.io/jnpr2 (DOI 10.17605/OSF.IO/JNPR2).

**Frozen on November 1, 2026, before any search-validation sample was drawn.** This file's GitHub commit date is the public timestamp. Under protocol section 4, Q2 is not changed in response to the validation sample. If recall in either cohort is below 80%, a revised set (Q3) is written using development cases only, frozen in a new file like this one, and validated on a new, separately drawn sample.

## Validation sampling (fixed now, before drawing)

- **Random seed:** 20261101. All random ordering for the validation samples uses this seed.
- **AQ:** the frame is Form 8-K filings dated January 1 to December 31, 2024 that report Item 2.01. Filings are put in random order with the seed. In that order, each is kept only if it reports a completed acquisition of a business by a registrant that files annual reports on Form 10-K. For each kept acquisition, the acquirer's next annual report (expected in 2025) is read to record whether management excluded the acquired business from its ICFR assessment (an eligible positive). Reading stops at 15 eligible positives or 100 acquisitions read.
- **NP:** the frame is final IPO prospectuses (Form 424B4) dated in 2024 for operating companies. Twenty are drawn in random order with the seed. For each, the first 10-K is read to record whether Item 9A contains the transition statement (an eligible positive).
- **Recall:** for each cohort, the share of eligible positives whose 10-K Q2 returns and the screen passes. Development cases (filings dated March 3–6, 2025) are not used.
- Every drawn item, its decision and the reason are published with the results.
